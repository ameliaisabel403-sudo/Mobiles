## Deploy
1. Upload the complete project folder to Vercel.
2. Keep `index.html` in the project root.
3. Use the default Vercel output for a static site; no build command is required.
4. Open the HTTPS Vercel URL on the phone. Camera access requires HTTPS.

## Connect Supabase
This is a browser/static app. The Supabase **anon/public key** is safe to use in a browser when your RLS policies are configured correctly. Never put the `service_role` key in this project.

You can either:
- Open **Settings** in the website and enter the Supabase Project URL and anon/public key, or
- Put the public values in `js/config.js`:
  - `DEPLOY_SUPABASE_URL`
  - `DEPLOY_SUPABASE_ANON_KEY`

After changing `schema.sql`, run the SQL in the Supabase SQL Editor, then redeploy/reload the site.

## Important
If an older deployment is cached, use a new deployment or hard refresh the Vercel site after uploading the fixed files.
